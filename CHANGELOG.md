## [0.2.0] - 2026-09-03

### Added

- GitHub Actions release workflow (`.github/workflows/release.yml`): automated build, test, tarball, checksums, dist/ update, and GitHub Release on tag push
- Release automation script (`dist/update-dist.sh`): updates version and checksums in all 10 dist/ package files via sed
- COPR SCM builder (`.copr/Makefile`): downloads source tarball and builds SRPM for Fedora COPR
- Packaging files (dist/) for 10 distributions: Entware, OpenWrt, Debian/Ubuntu, RPM (Fedora/RHEL/openSUSE), Alpine Linux, Arch Linux, Gentoo, Void Linux, NixOS, FreeBSD
- Packaging documentation (dist/README.md) with build instructions per distribution
- Gentoo: full overlay structure (`metadata/layout.conf`, `profiles/repo_name`, `profiles/categories`)
- Arch Linux: AUR `.SRCINFO` metadata file (auto-generated by `update-dist.sh`)
- Per-distro README.md with build/install instructions for Gentoo, Alpine, Void, Arch, RPM/COPR, NixOS, Debian/Ubuntu, OpenWrt, Entware, FreeBSD
- FreeBSD: `distinfo` file with SHA256 checksum and file size placeholders
- RPM: COPR `.repo` template file (`dist/rpm/aggregate6.repo`)
- NixOS: flake with overlay support (`dist/nix/flake.nix`)
- Debian: `uscan` watch file for upstream version tracking (`dist/debian/watch`)
- Debian: Vcs-Git and Vcs-Browser fields in `control`

### Changed

- `dist/README.md` rewritten: platform table with quick-install commands, directory structure, release automation docs, per-distro README links
- `README.md`: "Packaging" section replaced with "Installation — Distribution Packages" table with quick-install commands
- Debian `control`: fixed Vcs-Git/Vcs-Browser branch from `main` to `master`
- All dist/ source URLs switched from GitHub `/archive/` to stable `/releases/download/` URLs
- Alpine: APKBUILD moved to aports-compatible `testing/aggregate6/APKBUILD`
- Void: template moved to void-packages compatible `srcpkgs/aggregate6/template`
- OpenWrt: Makefile moved to feed-compatible `net/aggregate6/Makefile`, switched from `PKG_SOURCE_PROTO:=git` to tar.gz + `PKG_HASH`
- Entware: Makefile moved to feed-compatible `net/aggregate6/Makefile`, switched from `PKG_SOURCE_PROTO:=git` to tar.gz + `PKG_HASH`
- FreeBSD: switched from `USE_GITHUB` to `MASTER_SITES` with GitHub Releases URL
- Gentoo: ebuild `SRC_URI` uses GitHub Releases URL
- Arch: PKGBUILD `sha256sums` uses placeholder instead of `SKIP`
- RPM: `Source0` switched to full GitHub Releases URL
- NixOS: `default.nix` switched from `fetchFromGitHub` to `fetchurl` with Releases URL
- Debian: source format changed from `3.0 (native)` to `3.0 (quilt)` for upstream tarball support
- Comprehensive RFC-based test suite: 72 tests covering aggregation, edge cases,
  validation, IPv6 normalization, cascade, mixed v4/v6, and alignment
  (RFC 791, 1519, 3021, 4193, 4291, 4632, 5156, 5735, 5952, 6890)
- Patricia trie: `trie_insert()` with covered-prefix suppression and subtree pruning
- Patricia trie: `trie_aggregate()` — bottom-up sibling merge (post-order)
- Patricia trie: `trie_walk()` — pre-order traversal with numerically sorted output
- CIDR prefix parser with `inet_pton`, IPv4/IPv6 auto-detection, host-bit masking
- Full `aggregate_prefixes()` orchestration: parse → insert → aggregate → walk → output
- IPv4/IPv6 address family filtering via `-4`/`-6` flags

## [0.1.0] - 2025-09-02

### Added

- CLI with `-h`/`--help`, `-v`/`--version`, `-4` (IPv4 only), `-6` (IPv6 only) flags
- Read CIDR prefixes from stdin, skip empty lines and comments
- Passthrough stub for prefix aggregation (prints input unchanged)
- Patricia trie data structure stubs (`trie_create`, `trie_destroy`)
- Makefile with `all`, `clean`, `install`, `test` targets
- Cross-compilation support via `CC` variable
- Basic shell test suite
